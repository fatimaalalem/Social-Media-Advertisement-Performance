# Social Media Advertisement Performance Dashboard

This project analyzes social media advertisement campaigns using Power BI.

- Campaign Performance
- Campaign Diagnostics
- Engagement & Activity
- Audience Analysis
- Ad Targeting & Effectiveness

- Purchases
- Engagements
- Impressions

- Data Visualization
